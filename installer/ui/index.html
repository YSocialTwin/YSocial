YSocial

Installs an isolated Python environment and YSocial. Your data stays in the folder below.

Optional components

Not included: LLM servers (Ollama, vLLM, OpenAI-compatible endpoints) and PostgreSQL are external; SQLite is the default database. Profile pictures are downloaded on first start.

Advanced options

Same flags as the ysocial command line.

Binding to 0.0.0.0 exposes YSocial to your network.
