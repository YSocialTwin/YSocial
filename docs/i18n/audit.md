# i18n audit: string census (F0-1)

Generated by `scripts/i18n/audit_strings.py`; re-run it to refresh. Figures are heuristic counts that size the work, not a list of strings to translate.

## Method

- **Templates**: Jinja tags are removed, then the HTML is parsed; a *string* is a text node containing at least two letters, plus the attributes `title`, `placeholder`, `alt`, `aria-label`, `label`, `data-title`, `data-tooltip` and the `value` of submit/button inputs. Text inside `<script>` and `<style>` is excluded. *Unique* de-duplicates identical strings inside the area.
- **Inline scripts**: `<script>` blocks without `src`; literals are quoted strings of two or more words.
- **Python**: AST walk of `flash()` and `jsonify()` calls (`jsonify` counted when it carries `error`, `message`, `msg` or `detail`); tests, migrations and alembic are skipped.
- **JavaScript**: own files only (minified or bundled files are listed as libraries); a literal is a quoted string of two or more words that does not look like code, a path or a URL. Tutorials are reported apart.
- **Manifests**: string values of `name`, `display_name`, `description`, `label`, `title`, `help`, `placeholder`, `tooltip`, `category`, `group`, `summary` in `meta/*.json`.

## Findings that affect the plan

- 129 of 570 `flash()` calls are f-strings and 26 pass a variable: they need rewriting with named placeholders (risk R1) before they can be marked.
- Core templates hold about 2363 unique strings; `admin` alone is 1941 (82% of the total).
- The simulation frontends (microblogging, forum, photo, shared, login, error pages) hold 601 unique strings: a much smaller catalogue than admin.
- Own JavaScript has 789 text-like literals (141 in tutorials); `lightbox.js` alone has 113, so the JS runtime (F1-5) is needed for the admin pages too.
- Training Modules is the largest plugin (56 templates, 663 template strings). Manifest strings are concentrated in `y_agents_plugins` and `reactive_agents`.
- `<html lang=...>` is hard-coded in 6 core templates (the plan counted 11; the login and error pages now share `login/scene_base.html`, and 4 more live in plugin templates).
